The arguments are expected to be an arbitrarily long list of search queries. Valid search queries are: - `name:<pattern>` Fully matches the tile name using a regex pattern (e.g. `baba` will match baba only, but `baba.*` will match all tiles starting with baba) - `tiling:<tiling mode>` Matches the tiling mode - `source:<string>` Matches the source the tile came from - `tag:<string>` Matches if the tile has this tag # Arguments 1...
